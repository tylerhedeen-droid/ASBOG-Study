# USACE ASBOG Study Tool — v5.7

## Dedicated FG exams
- 650-question learning bank remains available for ordinary practice.
- Added FG Practice Exam Form A: 140 exam-only questions.
- Added FG Practice Exam Form B: 140 exam-only questions.

- Exam-only questions do not appear in Mixed, Standard FG Mix, Single Domain, Calculation, Visual, or Scenario practice.
